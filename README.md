# MIVIA-AID presentation

Academic presentation site for *Offline Accident-Onset Timestamp Estimation on MIVIA-AID with VideoMAE and Dilated Temporal Convolutions* (Adabala and Chakkaravarthy).

## Local

```bash
bun install
bun run dev
```

## Production

```bash
bun run build
bun run start
```

The app is a Next.js App Router project and deploys on Vercel with default settings.
